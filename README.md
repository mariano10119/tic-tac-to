# tic-tac-to
For our project we created a two player Tic-Tac-Toe game using C.Players take turns placing X or O on a 3x3 board.The first player to win 3 in a row wins the game.The game also has a scoreboard that tracks, losses, and draws even after the program is closed.

HOW TO RUN:

1: Download the tic-tac-toe file
2. Open terminal with he file in the folder
3. Run the program

HOW TO PLAY
1. Decide who is X and who is O
2. Player X and O alternate turns
3. First with 3 in a row wins

HOW WE SAVED SCORES

The player automatically saves Player X wins, PLAYER O wins, draws in a file we have named scores.txt.The file stores three numbers in that order like 3,2,1.The scores are loaded again when the program restarts.
